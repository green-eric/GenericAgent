## 2. 增强方案（4 模块）

### 模块 1: 多因子分层回测（P0）

**目标**: 验证 IC 单调性，确保因子分层有效

```python
# 新增函数: run_factor_layered_backtest(engine, factor_keys, n_layers=5)
# 对每个因子:
#   1. 按因子分将股票分为 5 层（quintile）
#   2. 计算每层未来 N 日等权收益
#   3. 输出 IC 单调性 = (层5收益 - 层1收益) / 层1收益
#   4. 验收: 单调性 > 70%（即层5>层4>层3>层2>层1 的比例）
```

**实现位置**: `ic_analysis.py` 新增 `run_factor_layered_backtest()`

### 模块 2: 换手率分析（P0）

**目标**: 评估策略换手频率，估算交易成本

```python
# 新增函数: analyze_turnover(engine, rebalance_days, top_n)
# 每期:
#   1. 记录当期选中的股票集合
#   2. 与上期比较，计算换手率 = |新加入| / |总持仓|
#   3. 输出: 平均换手率、换手率分布、换手率-收益相关性
# 验收: 换手率分析报告完整
```

**实现位置**: `backtest.py` 新增 `analyze_turnover()` 方法

### 模块 3: 最大回撤独立指标（P1）

# 修改: backtest.py --mode backtest 输出中增加:

### 模块 4: 基准对比（P1）

**目标**: 与沪深300指数对比胜率
