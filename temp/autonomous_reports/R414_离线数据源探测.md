## 一、探测结果

| 数据源 | 状态 | 数据量 | 耗时 |
|--------|------|--------|------|
| baostock | ✅ 可用 | 243行日K(1只股票1年) | 6.6s登录 |
| akshare 融资融券 | ✅ 可用 | 2000行 | 1.6s |
| 本地文件 | ✅ 可用 | 61个文件 | - |
| akshare 新浪日线 | ❌ 网络封锁 | - | - |
| akshare 腾讯日线 | ❌ API变更 | - | - |
| akshare 北向资金 | ❌ 函数名变更 | - | - |

## 二、baostock详细验证

- 登录: ✅ 成功
- 日K字段: date, code, open, high, low, close, volume, amount
- 数据质量: ✅ 完整，无缺失
- 频率: 日K，前复权(adjustflag=2)

## 三、结论与建议

1. **baostock是最优数据源** — 免费、稳定、完整，可替代东方财富接口
2. **akshare部分接口可用** — 融资融券数据可获取，但股票行情接口被封锁
3. **本地数据可复用** — wq101因子数据(98KB)可直接用于分析
