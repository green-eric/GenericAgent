## 二、各项目的业务逻辑深度分析

### 2.1 ScoreSys — A股智能选股系统

**README自述**: "基于季报+年报的基本面量化评分系统，支持4300+只A股批量扫描"

**五维评分模型**:
- 成长性 × 25%（营收YoY、净利润YoY等）
- 盈利能力 × 30%（ROE、毛利率、净利率等）
- 现金流质量 × 20%（OCF/净利润、收现比等）
- 偿债风险 × 15%（资产负债率、流动比率等）
- 估值 × 10%（PE_TTM等）

**评级**: A+/A/B+/B/C/D（D=被一票否决或总分=0）

**架构核心模块** (按数据流):
```
main.py → data_provider.py → fetcher.py → akshare(数据源)
                   ↓
            calculator.py → scorer.py
                   ↓
            database.py(SQLite) → excel_export.py(输出)
```

**关键发现**:
1. **data_provider.py (770行)**: 最大模块，封装了 `_IndustryCache`、`_DataCache`、`DataProvider` 三类，含代理管理（`_ensure_proxy_cleared`）、NeoData查询、akshare行业获取
2. **calculator.py (652行)**: `IndicatorCalculator` 类，处理财务数据过滤(`_filter_by_ann_date防未来函数`)、季度拆分、YoY计算、TTM求和、杠杆计算
3. **database.py (440行)**: `StockDatabase` 类，SQLite存储，支持财务数据CRUD
4. **fetcher.py (334行)**: 数据获取层，含 `TokenBucketRateLimiter` 限流、`LeakyBucketRateLimiter` 漏桶两种限流算法
5. **scorer.py (248行)**: 最终评分计算
6. 有**1323个JSON文件**（缓存数据），说明大量离线数据
7. 支持**断点续传**和**防未来函数**（`--date`参数指定评估日期）

**数据源**: akshare（同花顺三表）+ 百度估值

### 2.2 AnnualScorer — 年度财报评分系统

**架构核心模块**:
```
annual_scorer.py(主入口383行) → fetcher.py → 数据源
        ↓
    scorer.py(330行) → 百分位排名评分
        ↓
    industry.py(297行) → 行业分类
        ↓
    db.py(244行, SQLite) → exporter.py → Excel输出
```

**关键发现**:
1. **scoring逻辑**: 使用 `percentile_rank` 百分位排名法，在行业内相对排名
   - 4个维度: profit(盈利)、growth(增长)、ocf(经营现金流)、debt(偿债)
   - `_apply_completeness_penalty` 数据完整度惩罚
   - `_apply_negative_profit_penalty` 负利润惩罚
2. **industry.py**: 多策略行业分类
   - 从内容提取行业 (`extract_industry_from_content`)
   - 从名称推断行业 (`infer_industry_from_name`)
   - akshare行业成分股获取 (`build_industry_from_akshare`)
   - 线程池并发 (`ThreadPoolExecutor`)
3. 纯函数式架构（无class），配置驱动（`config.py`）
4. 有完整的tests目录 (11个测试文件)

**与ScoreSys的区别**: AnnualScorer更专注于**年度财报**的行业内百分位排名，ScoreSys更全面（五维+实时数据+回测+交易）

### 2.3 BullishForMonitoring — A股利好监控+短线量化交易系统

**版本**: 9.3.0 | **技术栈**: Python后端 + TypeScript/Vite/Echarts前端

**README自述**: "功能完整的A股市场监控和短线量化交易系统"

**八维度评分系统**:
| 维度 | 模块文件 | 权重 | 描述 |
|------|---------|------|------|
| 情绪 | sentiment.py | 6 | 新闻影响度+技术面情绪兜底 |
| 板块 | sector.py | 8 | 板块热度幂函数归一化 |
| 龙头 | leader.py | - | 龙头股识别 |
| 资金 | capital.py | - | 资金流向 |
| 量价 | volume_price.py | - | 量价关系 |
| 强势 | strength.py | - | 强势股特征 |
| 稳定性 | stability.py | - | 波动稳定性 |
| 业绩质量 | earnings.py | - | 量化财务+新闻关键词混合 |

**架构** (前后端分离):
```
前端: TypeScript + Vite + TailwindCSS + Echarts
        ↕ HTTP (port 9004)
后端: monitor.py (主入口, server/backtest/calibration/live模式)
      ├── modules/ (76个文件)
      │   ├── scorer/ (八维度评分引擎)
      │   ├── market/ (市场数据)
      │   ├── trading/ (交易策略)
      │   ├── risk/ (六维风控)
      │   ├── sector_registry.py (804行, 板块层级体系)
      │   ├── sector_manager.py (498行, 板块管理)
      │   ├── trading_calendar.py (交易日历)
      │   ├── validators.py (579行, 数据验证)
      │   ├── retry.py (重试+熔断器)
      │   ├── seen_store.py (去重存储)
      │   └── utils.py (513行, ConfigManager单例)
      └── tools/ (10个诊断工具)
```

**关键发现**:
1. **最复杂的项目**: 76个Python模块 + TypeScript前端，功能涵盖监控/评分/回测/交易/风控全链路
2. **六维风控**: 市场风险、流动性、连续亏损、最大回撤、交易频率、板块限制
3. **市场环境自适应**: 自动识别牛市/熊市/震荡市，动态调整评分权重和交易阈值
4. **三层缓存**: 前端缓存、服务器内存缓存、数据层LRU缓存
5. **10个诊断工具**: API状态检查、一致性诊断、仓位问题诊断、评分解释、性能基准测试、压力测试、参数标定等
6. **配置化**: config.yaml + config/ 目录(10个拆分配置文件)，80+核心评分参数
7. 支持**飞书推送**、**Web界面**、**回测引擎**
