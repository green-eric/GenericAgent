## ⏰ 调度方案

### 方案 A: Windows 任务计划程序 (推荐)

```powershell
# 每晚 23:00 启动批处理
schtasks /create /tn "GA_Nightly_Batch" /tr "D:\GenericAgent\temp\nightly_batch.bat" /sc daily /st 23:00
```

### 批处理脚本 (`nightly_batch.bat`)

```batch
@echo off
cd /d D:\GenericAgent\temp
echo [%date% %time%] 夜间批处理开始 >> logs\nightly.log

echo [1/6] 因子 IC 回测...
python ic_test_v2.py >> logs\nightly.log 2>&1

echo [2/6] RPS20 回测...
python rps20_fusion_bt_v2.py >> logs\nightly.log 2>&1

echo [3/6] 因子相关性分析...
python factor_redundancy.py >> logs\nightly.log 2>&1

echo [4/6] 临时文件清理...
python -c "import cleanup; cleanup.run()" >> logs\nightly.log 2>&1

echo [5/6] 知识图谱更新...
python autonomous_reports/update_index.py >> logs\nightly.log 2>&1

echo [6/6] 完成
echo [%date% %time%] 夜间批处理完成 >> logs\nightly.log
```

### 执行顺序建议

```
23:00  数据质量检查 (轻量，确认数据就绪)
23:15  因子 IC 回测 (CPU密集，1h)
00:15  RPS20 策略回测 (CPU密集，45min)
01:00  因子相关性分析 (CPU密集，20min)
01:30  ScoreSys 全量评分 (若编写完成)
02:00  参数优化 (CPU密集，2h，周末跑)
04:00  清理+索引更新 (IO轻量)
04:30  生成日报摘要
```

## ⚠️ 注意事项

1. **部分任务脚本不存在**: #1 ScoreSys全量评分、#6 数据质量检查、#8 临时文件清理需编写
2. **GPU 不可用**: Intel Iris Xe 不适合深度学习训练，仅适合传统量化回测
3. **内存限制**: 16GB 内存下单个 Python 进程建议不超过 8GB
4. **建议**: 先手动跑一次 `nightly_batch.bat` 验证流程，再设置定时任务
