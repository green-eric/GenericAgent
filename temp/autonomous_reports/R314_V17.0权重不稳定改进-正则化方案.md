# R314 — V17.0 权重不稳定性改进（相关系数 0.504 → 目标 >0.7）

> 📅 2026-05-30 | 自主行动 TODO#10 | 基于 V17.0 Walk-Forward 回测评估报告 + weight_optimizer.py

## 问题

V17.0 Walk-Forward 4折权重相关系数仅 **0.504**，远低于目标 0.7。

| 指标 | V16.9(旧) | V17.0(修复后) | 目标 |
|------|-----------|--------------|------|
| 折间权重相关系数 | 0.909(虚假) | 0.504(真实) | >0.7 |

V16.9的0.909是bug（每折用相同静态权重），V17.0修复后为真实值0.504。

## 根因分析

### 1. IC时变性强
- 不同训练窗口计算出的因子IC差异大（R276: 反转/盈利性/估值IC变化200~318%）
- 18个因子中仅5-6个IC稳定，其余随市场状态剧烈波动

### 2. 无正则化约束
- `compute_weights()` 无权重变化惩罚，相邻折权重可跳跃
- `max_single_weight=0.30` 仅限制单因子上限，不限制折间变化

### 3. 因子冗余
- 29个因子（V16.9）→ 18个因子（V17.0），但仍有高度相关因子组
- momentum/industry_momentum/alpha_momentum 同组，reversal/profitability 可能负相关

### 4. 训练窗口差异
- Fold1训练集6个月，Fold4训练集18个月，IC差异自然增大

## 改进方案

### 方案A：权重正则化（P0 推荐）

在 `compute_weights()` 中加入折间平滑约束：

```python
def compute_weights_with_regularization(ic_data, prev_weights=None, 
                                         lambda_reg=0.3):
    """带正则化的权重计算
    
    lambda_reg: 正则化强度
      0 = 无正则化（当前）
      0.3 = 30%保留上一折权重（推荐起点）
      0.5 = 50%保留（强约束）
    """
    new_weights = _raw_compute_weights(ic_data)
    
    if prev_weights is None:
        return new_weights
    
    # 混合：w = (1-λ) * w_new + λ * w_prev
    blended = {}
    for f in set(new_weights) | set(prev_weights):
        w_new = new_weights.get(f, 0.0)
        w_prev = prev_weights.get(f, 0.0)
        blended[f] = (1 - lambda_reg) * w_new + lambda_reg * w_prev
    
    return _normalize(blended)
```

**预期效果**：相关系数 0.504 → 0.65~0.75

### 方案B：因子聚类降维（P1）

将高度相关因子聚类，用组权重替代单因子权重：

| 聚类组 | 因子 | 组权重 |
|--------|------|--------|
| 动量组 | momentum, industry_momentum, alpha_momentum | 共享权重 |
| 价值组 | valuation, profitability, growth | 共享权重 |
| 反转组 | reversal, alpha_rsi | 共享权重 |
| 波动组 | volatility_squeeze, volatility_deviation, volatility_ma | 共享权重 |
| 独立因子 | turnover, cash_flow, leverage 等 | 独立权重 |

**预期效果**：减少权重变量从18→10，降低过拟合

### 方案C：延长IC平滑窗口（P1）

当前 `ic_smoothing=2.6`，增大至 `4.0~5.0`：

```python
# config.yaml
weight_optimizer:
  ic_smoothing: 4.0  # 从2.6增大
  halflife_days: 90  # 从60增大
```

**预期效果**：权重更平滑，但响应速度降低

### 方案D：增加训练窗口一致性（P2）

将4折训练集统一为滚动12个月窗口：

```
Fold1: Train[2024-01, 2024-12] → Test[2025-01, 2025-03]
Fold2: Train[2024-04, 2025-03] → Test[2025-04, 2025-06]
Fold3: Train[2024-07, 2025-06] → Test[2025-07, 2025-09]
Fold4: Train[2024-10, 2025-09] → Test[2025-10, 2025-12]
```

**预期效果**：训练窗口一致，IC可比性提升

## 推荐执行顺序

1. **立即**：方案A (λ=0.3) — 一行代码改动，效果显著
2. **短期**：方案C (ic_smoothing: 4.0) — 配置改动
3. **中期**：方案B + D — 需要重构walk_forward结构
