## 三、接入方案建议

### 🏆 推荐方案：QMT (miniQMT)

**推荐理由：**
1. **篮子委托**：ScoreSys每次调仓约10~20只股票，QMT的篮子委托可一次性下单，减少滑点
2. **低延迟直连**：券商级延迟，适合中低频策略(5天调仓周期)
3. **稳定性最强**：7×24h运行，不依赖第三方平台
4. **零额外成本**：仅需券商开户门槛

**对接架构：**
```
ScoreSys信号(JSON) → 信号解析模块 → miniQMT篮子委托 → 券商交易
```

**核心对接代码框架：**
```python
from xtquant import xtconstant
from xtquant.xttrader import XtQuantTrader
from xtquant.xttype import StockAccount

# 1. 读取ScoreSys信号
signals = json.load(open('output/live_signals_latest.json'))
buy_list = [s for s in signals['signals'] if s['action'] == 'BUY']

# 2. 连接QMT
trader = XtQuantTrader(r'C:\国金QMT\userdata_mini', session_id)
account = StockAccount('你的资金账号')

# 3. 篮子委托(等权重)
weights = {s['code'].split('.')[0]: 1.0/len(buy_list) for s in buy_list}
trader.basket_order(account, weights)
```
