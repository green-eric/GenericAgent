## 🔍 核心发现

### 1. Redis 服务器 — 实时股票数据宝库

**状态**: ✅ 运行中 (localhost:6379)

| 数据类型 | Key数量 | 说明 |
|----------|---------|------|
| K线数据 | 968只股票 | 日K线，86个数据点/只，覆盖2026-01-05~2026-05-18 |
| 行情数据 | 387只 | 实时行情(名称/价格/涨跌幅/成交量/市值等) |
| 新闻数据 | 3组 | 24h内新闻，420条抓取→820条去重→671条股票相关 |
| 回测数据 | 2个 | backtest:redis:data + timestamp |
| 市场情绪 | 1个 | bullish:market |

**K线数据结构**:
```
[日期, 开盘, 收盘, 最高, 最低, 成交量]
["2026-05-18", "90.00", "91.14", "96.10", "89.99", "752331"]
```

**K线类型**: 85(前复权)=470只, 65(后复权)=498只

**行情样例**:
```json
{"name": "联合精密", "price": 42.53, "pct": -1.91, 
  "vol": 31486, "turnover": 4.67, "market_cap": 28.68}
```

**意义**: ScoreSys的stock_data.db(quotes表)只有5/15前的数据，
Redis中有更新(5/18)且更丰富的数据，可作为数据源补充。

### 2. ws/stock — 七维选股系统

**位置**: `D:/ws/stock/`

| 文件 | 说明 |
|------|------|
| `build_v15.py` (14KB) | A股量化选股v15 — 七维升级版 |
| `stock_selection_v15.xlsx` (7.7KB) | 选股结果 |
| `选股逻辑文档.md` (1.8KB) | 选股逻辑说明 |

**选股逻辑** (七维评级):
1. A+级季报: 营收同比>10%, 净利同比>10%
2. B级年报: ROE>10%, 毛利率>20%
3. 市值>50亿
4. PE<100
5. 趋势因子: 多头排列+10, 空头排列-5
6. 年报评分加权: 综合分=季度总分×60%+年报总分×40%

**意义**: 这是另一套独立的选股体系，与ScoreSys互补。
可考虑将七维因子融入ScoreSys评分体系。
