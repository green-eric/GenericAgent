# R258 定时任务体系架构整合报告

## 状态：✅ 完成

## 背景
存在两套独立调度器，功能重叠、维护困难：
- `reflect/scheduler.py`：轮询式(120s)，读取sche_tasks/*.json，通过agent执行prompt
- `temp/task_scheduler.py`：APScheduler，硬编码2个Python任务

## 方案
创建 `unified_scheduler.py`，单一APScheduler入口，合并两套调度器的所有功能。

## 新架构

```
unified_scheduler.py (单一入口)
├── sche_tasks/*.json (配置源，保留兼容)
│   ├── daily_backtest.json → 工作日15:00
│   ├── scoresys_check_score_done.json → 每30分钟
│   └── scoresys_daily_backtest.json → 已禁用
│
├── 注册3个APScheduler任务：
│   1. daily_backtest       — 工作日15:00  回测+评分完整流程
│   2. scoresys_check_score — 每30分钟     检查评分完成+推送报告
│   3. rps20_daily_backtest — 工作日16:00  RPS20每日回测
│
├── check_and_push_score.py (新增，scoresys_check_score任务依赖)
│   └── 检查score_result_*.xlsx → 未推送则调用push_report.py
│
└── scheduler_logs/ (日志目录)
    ├── scheduler_YYYYMMDD.log (主日志)
    └── {task}_{datetime}.log (每个任务执行日志)
```
