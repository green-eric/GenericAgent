# Mini-SOP 3: 记忆更新模式

## 触发
发现新工具/新用法/新经验需要持久化时

## 流程
1. **判断层级** — 
   - L1(global_mem_insight.txt): 索引，只记文件名和一行描述
   - L2(global_mem.txt): 事实，记具体参数/用法/路径
   - L3(memory/*.md): SOP，记完整操作流程
2. **读取现有** — 先read目标文件，避免重复/冲突
3. **增量写入** — 用file_patch追加，不覆盖已有内容
4. **同步L1** — L2/L3有变更时必须同步更新L1索引

## L1索引格式
```
L3: tool_name(一句话描述) | tool2_name(一句话描述)
```

## L2事实格式
```
### 工具名 v版本
- **路径**: xxx
- **用法**: `命令`
- **注意**: xxx
```

## 关键原则
- 先读后写，file_patch修改，不覆盖
- L1只存索引，细节放L2/L3
- 每次L2/L3变更后必须同步L1
