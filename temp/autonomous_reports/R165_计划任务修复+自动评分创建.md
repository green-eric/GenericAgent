Windows 计划任务从 InteractiveToken 改为 S4U/Password 类型时，
必须提供用户密码。这是操作系统安全策略，无法绕过。

## 需要用户操作

### 方案A: 手动修改计划任务 (推荐)
1. 打开 "任务计划程序" (taskschd.msc)
2. 找到 RPS20_DailyBacktest → 属性 → 常规
3. 改为 "不管用户是否登录都运行" + 勾选 "使用最高权限"
4. 输入密码确认
5. 对 ScoreSys-UpdateIndustryStats 重复

### 方案B: 用命令行 (需提供密码)
```
schtasks /change /tn RPS20_DailyBacktest /ru green /rp YOUR_PASSWORD
schtasks /change /tn ScoreSys-UpdateIndustryStats /ru green /rp YOUR_PASSWORD
```

### 创建自动评分任务
在修复登录方式后，创建 ScoreSys_DailyScore:
- 时间: 每日 16:00 (收盘后)
- 命令: python main.py --from-db --all --save-db
- 路径: D:\Project\ScoreSys
