## 1. 系统概述

本系统通过 **NeoData 自然语言金融数据 API** 获取 A 股最新财务报告，自动解析关键指标与行业分类，基于**行业内百分位评分**生成 A~E 五级评级，输出 Excel 报告和 JSON 原始数据。

### 🎯 V3.8 核心特性

| 特性 | 说明 |
|------|------|
| 📁 统一目录管理 | 所有文件（输入、输出、数据库、日志）均在同一文件夹，自动创建 |
| ⏰ 时间戳防覆盖 | 输出文件名自动加上时间戳，避免覆盖历史数据 |
| 💾 SQLite 增量缓存 | 首次全量获取，之后每天仅更新过期或缺失的股票 |
| 📊 报告期分类存储 | 财务数据按报告期（年报/一季报/半年报/三季报）存储 |
| 📅 披露截止日保护 | 次年4月30日前，即使缓存超400天也不会提前失效 |
| 🏭 六级行业覆盖 | 行业分类六级兜底策略，覆盖率 >95% |
| 📈 置信度标记 | 低完整度股票总分打折，标记置信度等级 |
| ⏱️ 全局超时保护 | 可设置的运行时间上限，避免意外长时间卡死 |
| 📝 失败追踪 | 新增"获取失败股票"工作表，便于快速定位 |
| ⚡ 批量写入 | 批量写入数据库，显著提升缓存效率 |
| 💓 心跳日志 | 每完成20只股票输出一次进度和耗时 |

## 3. 核心模块

### 3.1 配置管理 (Config 类)

所有参数集中管理，支持命令行修改：

```python
class Config:
    # 路径配置
    base_dir: str          # 工作目录
    
    # 并发配置
    finance_workers: int   # 财务数据并发数
    
    # API配置
    api_timeout: int       # 单次API超时（秒）
    global_delay: float   # 每只股票提交间隔（秒）
    
    # 缓存配置
    cache_max_age_annual: int      # 年报缓存有效期（天）
    cache_max_age_quarterly: int   # 季报缓存有效期（天）
    annual_disclosure_deadline: tuple  # (月, 日)
    
    # 评分配置
    min_industry_samples: int     # 行业内最少股票数
    market_fallback_discount: float  # 全市场评分折扣
    low_completeness_penalty: float  # 低完整度评分折扣
    global_timeout: int           # 全局超时（秒）
```

### 3.5 评分模型

#### 3.5.1 百分位计算

| 条件 | 计算方式 |
|------|----------|
| 行业明确且样本 ≥5 只 | 按行业内百分位 |
| 行业样本不足或未分类 | 使用全市场百分位 × 0.95 |

#### 3.5.2 四维加权评分体系

```
                    ┌─────────────────┐
                    │    总评分       │
                    │  满分100分      │
                    └────────┬────────┘
                             │
        ┌────────────────────┼────────────────────┐
        │                    │                    │
        ▼                    ▼                    ▼
┌───────────────┐    ┌───────────────┐    ┌───────────────┐
│   盈利能力    │    │    成长性    │    │    现金流    │
│   权重 35%   │    │   权重 30%   │    │   权重 15%   │
└───────┬───────┘    └───────┬───────┘    └───────┬───────┘
        │                    │                    │
   ┌────┴────┐          ┌────┴────┐          ┌────┴────┐
   │         │          │         │          │         │
   ▼         ▼          ▼         ▼          ▼         ▼
┌─────┐  ┌─────┐   ┌─────┐  ┌─────┐   ┌─────────┐
│ ROE │  │毛利 │   │营收 │  │净利 │   │经营现金 │
│ 40% │  │率40%│   │增速 │  │增速 │   │流/净利  │
│     │  │     │   │ 40% │  │ 60% │   │  100%   │
└─────┘  └─────┘   └─────┘  └─────┘   └─────────┘
```

**评分公式**：

```
盈利能力 = 0.4 × ROE百分位 + 0.3 × 毛利率百分位 + 0.3 × 净利率百分位
成长性   = 0.4 × 营收同比百分位 + 0.6 × 净利润同比百分位
现金流   = 经营现金流/净利润 百分位
偿债风险 = 资产负债率百分位（越低越好）

总评分   = 0.35 × 盈利 + 0.30 × 成长 + 0.15 × 现金流 + 0.20 × 偿债
```

#### 3.5.3 特殊惩罚规则

| 情况 | 处理方式 |
|------|----------|
| 净利润 < 0 **且** 经营现金流净额 < 0 | 总分最高 15 分 |

#### 3.5.4 数据完整度处理

| 完整度等级 | 条件 | 评分折扣 | 置信度 |
|------------|------|----------|--------|
| 高 | 7项核心指标齐全 | 无 | 高 |
| 中 | 缺失 1-3 项 | 无 | 中 |
| 低 | 缺失 4+ 项 | × 0.9 | 低 |

> ⚠️ **注意**：V3.8 优化后，低完整度股票不再强制压制评级，仅标记置信度为"低"

#### 3.5.5 评级标准

| 评分区间 | 评级 | 说明 |
|----------|------|------|
| ≥75 分 | **A** | 绩优股 |
| ≥55 分 | **B** | 良好股 |
| ≥40 分 | **C** | 一般股 |
| ≥25 分 | **D** | 较差股 |
| <25 分 | **E** | 边缘股 |

## 4. 增量缓存机制

### 4.1 数据库结构 (SQLite)

#### stocks 表

```sql
CREATE TABLE stocks (
    ts_code    TEXT PRIMARY KEY,  -- 股票代码
    name       TEXT,               -- 股票名称
    industry   TEXT,              -- 行业分类
    update_time INTEGER            -- 更新时间戳
);
```

#### financial_reports 表

```sql
CREATE TABLE financial_reports (
    ts_code     TEXT,              -- 股票代码
    report_date  INTEGER,           -- 报告期日期 (YYYYMMDD)
    report_type  TEXT,             -- 报告类型 (年报/年一/半年/三季)
    last_update  INTEGER,          -- 最后更新时间戳
    PRIMARY KEY (ts_code, report_date, report_type)
);
```

## 6. 使用指南

### 6.1 基本用法

```bash
python stock_analyzer_v3.8.py
```

### 6.2 完整参数示例

```bash
python stock_analyzer_v3.8.py \
    --base-dir ./workplace \
    --stock-file xuan.txt \
    --workers 6 \
    --timeout 1800 \
    --force-refresh
```

### 6.3 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--base-dir` | 脚本所在目录 | 工作目录，不存在则自动创建 |
| `--stock-file` | `xuan.txt` | 股票列表文件名（支持相对/绝对路径） |
| `--workers` | `8` | 并发线程数 |
| `--timeout` | `3600` | 全局超时秒数（0 表示不限） |
| `--force-refresh` | False | 忽略缓存，全量重新获取 |
| `--no-retry-failed` | False | 禁止失败重试补采 |
| `--no-industry-patch` | False | 禁止行业 API 补调 |

## 8. 注意事项

| ⚠️ 重要提示 |
|------------|
| 📅 财报披露时间有限制，缓存有效期已加入披露截止日保护，避免季报空窗期无效刷新 |
| 🔄 API 若频繁返回空，系统会自动暂停后重试，所有异常均记录在日志和 Excel 中 |
| 🏭 内置行业映射表为手工整理，可能存在少量偏差，建议定期用外部 `industry_map.json` 更新 |
| 📊 低置信度（数据完整度低）的股票评分可信度较低，报告中会标注置信度，建议人工复核 |
| ⏱️ 首次全量获取时间较长（与股票数量正相关），后续每日运行仅需更新少量股票，大幅缩短耗时 |
