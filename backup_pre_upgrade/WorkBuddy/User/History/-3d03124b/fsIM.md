## 协同工作流程

### 完整A股分析流程
```
1. 年报分析系统
   └─> 获取并分析年报数据
   └─> 生成年报评分和A级股票列表

2. 季度评分系统
   ├─> 从年报中提取最新季度数据
   ├─> 计算季度评分
   └─> 筛选季报A级股票

3. 交叉验证
   └─> 年报A级 ∩ 季报A级 = 优选股票
   └─> 生成JSON交叉验证报告
```
