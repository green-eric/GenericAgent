# A股年报增长率分析项目 - 最终报告

## 项目概述

本项目旨在构建一个完整的A股市场年报增长率分析系统，专注于识别和筛选2025年年报中增长率超过50%的高成长性股票。通过东方财富金融工具集API获取数据，运用先进的算法进行多维度分析，为投资决策提供科学依据。
