# 季度评分系统完整报告

## 📊 系统概述

本系统是一个独立的A股季度评分系统，主要功能包括：

- **季度数据提取**: 从年报文本中自动提取最新季度财务指标
- **季度评分计算**: 基于季度和年报数据的综合评分
- **交叉验证选股**: 通过年报A级 ∩ 季报A级的交集筛选优选股票

## 📋 使用说明

### 基本命令
```bash

python quarterly_scorer.py --test

# 随机验证10只股票（本地测试模式）
python quarterly_scorer.py --verify 10 --local-test

# 强制刷新季度数据
python quarterly_scorer.py --force

# 完整运行（需要API token）
python quarterly_scorer.py
```

### 参数说明
- `--test`: 运行自测并退出
- `--verify N`: 随机取N只股票端到端验证
- `--force`: 强制刷新季度数据
- `--local-test`: 本地测试模式（不调用API）

## 🔄 与年报系统集成

### 协同工作流程
```
1. 年报分析系统
   └─> 获取并分析年报数据
   └─> 生成年报评分和A级股票列表

2. 季度评分系统
   ├─> 从年报中提取最新季度数据
   ├─> 计算季度评分
   └─> 筛选季报A级股票

3. 交叉验证
   └─> 年报A级 ∩ 季报A级 = 优选股票
   └─> 生成JSON交叉验证报告
```

### 技术集成点
- **数据库共享**: 使用同一个stock_cache.db
- **数据一致性**: 统一的财务指标标准
- **评分标准**: 相同的5D评估体系
- **行业分组**: 统一的分组排名机制
