## 技术架构验证

### TTM计算引擎
```python
# 正确实现：
ttm["roe_ttm"] = round(profit_sum / net_assets * 100, 2)
```
- profit_sum: 近4季度净利润总和
- net_assets: 最新季度净资产数据
- 严格避免使用年报ROE兜底

### 数据源优先级策略
- 成长性指标 → 最新单季报
- 盈利能力指标 → TTM（近4季度滚动）
- 偿债风险指标 → 最新季报
- 现金流质量 → TTM
