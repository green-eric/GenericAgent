## revenue_yoy/profit_yoy取值Bug修复 (15:21-15:30)

### 根本原因
API返回文本中，每个子段落以"根据...发布的财报数据，统计截止日期为YYYYMMDD的Qx单季报/年报"开头。
旧代码用"统计截止日期为YYYYMMDD的..."作为锚点拆block，导致：
1. 多个子段落被合并到一个block中
2. 取到的revenue_yoy/profit_yoy可能来自错误的段落

### 关键发现
- **单季报只有"归母净利润同比增长"，没有"营业收入同比增长"**
- **年报同时有营收同比和净利润同比**

### 修复方案
1. 新增 `_extract_all_report_sections()` 按子段落拆分，每段标记报告类型
2. `fetch_quarterly_data()` 中：
   - 分离单季报和年报段落
   - 最新单季指标从最新单季报段落取
   - revenue_yoy: 单季报没有则从最新年报取
   - profit_yoy: 单季报没有则从最新年报取
   - TTM计算只用单季报段落

### 测试结果
10只股票全部验证通过，revenue_yoy和profit_yoy取值均正确

### 踩坑经验
- API返回的"统计截止日期"锚点不能直接用于拆分block，需要按"根据...发布的财报数据"拆分子段落
- 单季报不含营收同比增长字段，需要从年报兜底

## 字段提取逻辑全面修复 (15:41-16:00)

### 用户给出的字段规范表格
| 指标 | 提取关键词 | 数据源 |
|------|-----------|--------|
| ROE | 加权净资产收益率ROE / 净资产收益率ROE | TTM(计算) |
| 毛利率 | 销售毛利率 | TTM(计算) |
| 净利率 | 销售净利率 | TTM(计算) |
| 营收同比 | 营业收入同比增长 / 营收同比增长 | 最新单季 |
| 净利润同比 | 归母净利润同比增长 | 最新单季 |
| 资产负债率 | 资产负债率 | 最新单季 |
| 净利润 | ^归母净利润(严格行首匹配，排除同比/扣非) | TTM(累加) |
| 经营现金流 | 经营活动产生的现金流量净额 | TTM(累加) |

### 修复内容
1. **净利润提取**: 从包含匹配 `"归母净利润" in line` 改为严格行首匹配 `re.match(r"^归母净利润", line)`，并排除扣非/同比/现金含量
2. **经营现金流TTM**: 优先直接累加 `ocf_abs`(经营活动产生的现金流量净额)，仅在缺失时用净利润现金含量兜底计算
3. **资产负债率**: 优先直接提取"资产负债率"关键词，兜底用负债合计/资产合计计算
4. **_parse_single_block**: 新增 `debt_ratio` 字段和资产负债率提取逻辑

### 测试结果
8个测试全部通过 (ALL PASS)

### 踩坑经验
- 资产负债率需要两层提取：先直接提取关键词，再兜底用负债/资产计算
- 经营现金流TTM应优先直接取绝对值累加，而非用净利润现金含量间接计算
- 净利润行首匹配需要同时排除"扣非"和"现金"，否则可能误匹配
