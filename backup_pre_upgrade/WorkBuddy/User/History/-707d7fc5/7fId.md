# 季报项目长期记忆

## 项目信息
- **名称**：A股智能选股系统 V7.0.0
- **路径**：`D:/Project/QAScorer/`

- **依赖**：`AnnualScorer/stock_cache.db`（年报数据缓存）

## 关键架构
- **评分体系**：4维度（盈利40%+成长30%+现金流20%+风险10%），行业相对百分位排名
- **核心算法**：percentile_rank 用"位置索引"算法，升序中找第一个 >= value 的位置
- **数据策略**：单季看成长，TTM看盈利与现金，最新报表看杠杆
- **数据源**：NeoData API 获取季度数据，年报数据从 SQLite 缓存读取

## 踩坑经验
- percentile_rank 原代码在升序中用 `value >= v` 判断，导致最大值返回0分。正确做法是找第一个 `v >= value` 的位置。
- PowerShell 中 `cmd /c` 传递含反斜杠路径时需注意转义，建议用 Python 脚本文件执行测试。
- TTM ROE计算需要净资产数据，缺少时需使用年报数据兜底或设为None。
