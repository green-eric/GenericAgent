| 文件 | 说明 |

## 评分体系

### 4维度权重

| 维度 | 权重 | 子指标 | 子权重 |
|------|------|--------|--------|
| **盈利** | **35%** | ROE | 40% |
| | | 毛利率 | 30% |
| | | 净利率 | 30% |
| **成长** | **30%** | 营收同比 | 40% |
| | | 利润同比 | 60% |
| **现金流** | **15%** | 净利润现金含量 | 100% |
| **负债** | **20%** | 资产负债率（逆序） | 100% |

所有子指标均按**行业相对百分位排名**计分。行业内样本不足5只时，自动回退至全市场排名并乘以0.95折扣系数。

### 数据完整性惩罚

| **完整度** | **有效指标占比** | **惩罚系数** | **说明** |
|------------|------------------|--------------|----------|
| **high** | ≥70% | ×1.0 | 无惩罚 |
| **medium** | 40%~70% | ×1.0 | 无惩罚 |
| **low** | <40% 且 >1个指标 | ×0.9 | 轻度惩罚 |
| **ultra_low** | ≤1个指标 | ×0.675 | 0.9 × 0.75 复合惩罚 |

### 等级划分

| **等级** | **分数范围** |
|----------|--------------|
| **A** | ≥75 |
| **B** | 55-74 |
| **C** | 40-54 |
| **D** | 25-39 |
| **E** | <25 |

## 数据提取

### 季度段落识别

从 NeoData API 返回的年报全文中，通过正则匹配提取最新季度段落：

- 主模式：`统计截止日期为YYYYMMDD的Q[123]单季报`（支持 0331/0630/0930）
- 兜底模式：匹配任意单季报段落，过滤掉年报（1231）
- 取日期最新的季度段落

### 季度指标解析

| 指标 | 匹配关键词 |
|------|-----------|
| 销售毛利率 | `销售毛利率` |
| 销售净利率 | `销售净利率` |
| 营收同比增长 | `营业收入同比增长` / `营收同比增长` / `营业总收入同比增长` |
| 归母净利润同比增长 | `归母净利润同比增长` |

**注意**：Q1单季报不含营收同比增长字段，该指标将为 None。

### 季度评分合并策略

季度评分时，用季度提取的指标（毛利率、净利率、营收同比、利润同比）覆盖年报对应字段，其余指标（ROE、资产负债率、净利润现金含量等）继续使用年报数据。

**特殊规则**：
- ROE 为负数时，盈利子项得 0 分（不影响毛利率和净利率子项）
- 净利润为负且经营现金流为负时，总分上限为 15.0 分
- 百分位排名采用"位置索引"算法：升序排列中找 value 的位置 i，得分 = i/(n-1)×100

## 使用方法

### 环境准备

1. 确保 `../年报/stock_cache.db` 存在且包含年报数据
2. 配置 NeoData API Token：
   ```bash
   echo "your_token_here" > ~/.workbuddy/.neodata_token
   ```

### 命令

```bash
# 运行自测（验证数据提取和解析逻辑）
python quarterly_scorer.py --test

# 完整运行（从API获取季度数据，计算评分，输出交叉验证报告）
python quarterly_scorer.py

# 本地测试模式（不调用API，使用5只股票的模拟数据）
python quarterly_scorer.py --local-test

# 强制刷新季度数据（忽略缓存）
python quarterly_scorer.py --force

# 随机验证N只股票的端到端流程
python quarterly_scorer.py --verify 10 --local-test
```

### 参数说明

| **参数** | **类型** | **说明** |
|----------|----------|----------|
| `--test` | flag | 运行内置自测，验证段落提取、日期识别、指标解析 |
| `--verify N` | int | 随机取N只股票打印年报/季报评分对比 |
| `--force` | flag | 强制重新获取季度数据，忽略数据库缓存 |
| `--local-test` | flag | 本地测试模式，不调用 NeoData API |

### 输出

每次运行同时生成两份报告：

#### Excel 报告（`季度评分_YYYYMMDD_HHMMSS.xlsx`）

包含 3 个工作表：

| 工作表 | 内容 | 行数 |
|--------|------|------|
| **全部评分** | 所有股票的年报+季报评分明细，含等级颜色标记（A绿/B黄/C浅黄/D红）、交集优选★标记 | 全部股票 |
| **年报A∩季报A** | 交集优选股详情，含季度财务指标（毛利率、净利率、营收同比、利润同比）和年报核心指标 | 优选股 |
| **统计摘要** | 评分分布统计（A/B/C/D/E各级数量）、优选股数量 | — |

**Excel 列说明（全部评分表）：**

| **列** | **说明** |
|---------|----------|
| **代码/名称/行业** | 股票基本信息 |
| **年报总分/等级/盈利/成长/现金流/负债** | 年报4D评分明细 |
| **季报总分/等级/盈利/成长/现金流/负债** | 季度评分明细（季度指标覆盖后） |
| **季报毛利率/净利率/营收同比/利润同比** | 从年报文本提取的季度原始指标 |
| **数据来源** | `季报+年报补充` 或 `年报（无季度）` |
| **置信度/完整度** | 数据质量评估 |
| **季报日期** | 季度报告截止日期（如 20260331） |
| **交集优选** | 标记 `★` 表示年报A ∩ 季报A |

> 需要安装 `openpyxl`：`pip install openpyxl`。未安装时跳过 Excel 输出，仅生成 JSON。

## 工作流程

```
1. 加载 xuan.txt 股票列表（**4,344只**）
       ↓
2. 从 ../年报/stock_cache.db 加载年报数据
       ↓
3. 按行业分组，计算每只股票的年报评分
       ↓
4. 并发（**8线程**）调用 NeoData API 获取季度数据
   - 检查数据库缓存，已存在则跳过（除非 --force）
   - 从返回文本中提取最新季度段落
   - 解析毛利率、净利率、营收同比、利润同比
       ↓
5. 季度指标覆盖年报对应字段，计算季度评分
       ↓
6. 交集计算：年报A级 ∩ 季报A级 = **优选股票**
       ↓
7. 保存季度数据到数据库缓存
       ↓
8. 输出 Excel 报告（**3个工作表**：全部评分、优选股、统计摘要）
       ↓
9. 输出 JSON 交叉验证报告
```

## 关键修复记录

### percentile_rank算法修正（重要）
- **问题**：原代码在升序中用 `value >= v` 判断，导致最大值返回0分
- **修复**：改为正确的位置索引算法 - 升序找第一个 `v >= value` 的位置，降序找第一个 `v <= value` 的位置
- **影响**：所有股票的评分结果更准确，消除了最高值被错误评为0分的bug

- 统一版本号为V6.0.0
