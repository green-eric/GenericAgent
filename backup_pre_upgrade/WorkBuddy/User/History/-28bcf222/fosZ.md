# 季度评分系统 V6.0.0 测试报告

## 系统概述

本系统是一个独立的A股季度评分系统，主要功能包括：
- **季度数据提取**：从年报文本中自动提取最新季度财务指标
- **季度评分计算**：基于季度和年报数据的综合评分
- **交叉验证选股**：通过年报A级 ∩ 季报A级的交集筛选优选股票

## 核心功能

### 1. 季度数据提取
- 使用正则表达式匹配"统计截止日期为YYYYMMDD的Q[123]单季报"
- 自动跳过年报段落（1231），只提取季度数据
- 支持Q1/Q2/Q3单季报格式识别

### 2. 季度指标解析
解析以下关键财务指标：
- 销售毛利率 (%)
- 销售净利率 (%)
- 营业收入同比增长 (%)
- 归母净利润同比增长 (%)

### 3. 评分算法
季度评分 = 盈利得分 × 35% + 成长得分 × 30% + 现金流得分 × 15% + 负债得分 × 20%

其中：
- 盈利得分 = ROE得分 × 40% + 毛利率得分 × 30% + 净利率得分 × 30%
- 成长得分 = 营收同比得分 × 40% + 利润同比得分 × 60%

### 4. 交叉验证机制
```
年报A级股票集合: {r["ts_code"] for r in annual_scored if r.get("grade") == "A"}
季报A级股票集合: {r["ts_code"] for r in quarterly_scored if r.get("quarterly_grade") == "A"}
优选股票 = 年报A级 ∩ 季报A级
```

## 使用说明

### 基本命令
```bash
# 运行自测
python quarterly_scorer.py --test

# 随机验证10只股票（本地测试模式）
python quarterly_scorer.py --verify 10 --local-test

# 强制刷新季度数据
python quarterly_scorer.py --force

# 完整运行（需要API token）
python quarterly_scorer.py
```

### 参数说明
- `--test`: 运行自测并退出
- `--verify N`: 随机取N只股票端到端验证
- `--force`: 强制刷新季度数据
- `--local-test`: 本地测试模式（不调用API）
