## 核心理念

| 分析维度 | 方法 | 目的 |
|----------|------|------|
| **成长性** | 单季拆分 → 同比增速 | 捕捉最新业绩变化 |
| **盈利能力** | TTM 滚动四季度 | 消除季节扰动，看真实盈利 |
| **现金流质量** | TTM 经营现金流 | 验证利润含金量 |
| **偿债风险** | 最新资产负债表 | 监控财务安全底线 |
| **估值** | PE-TTM | 辅助判断价格合理性 |

**设计原则：单季看成长，TTM看盈利与现金，最新报表看杠杆。**

### 数据流

```
AkShare API
    │
    ▼
DataProvider（获取原始三表 + 行情）
    │
    ▼

    │
    ▼

    │
    ▼

```

### 1. 小规模测试（使用模拟数据，无需网络）

```bash
python main.py --mock --stocks 600519 000858 999999
```

> `--mock` 模式使用内置模拟数据，适合快速验证评分逻辑。其中 999999 为高杠杆测试股，会触发一票否决。

### 2. 单只股票真实评分

```bash
python main.py --stocks 600519
```

### 3. 批量扫描（从文件加载股票池）

```bash
python main.py --pool stock_pool.txt --workers 5 --rate-limit 0.3
```

### 4. 回测指定历史日期

```bash
python main.py --stocks 600519 000858 --date 2024-12-31 --show-veto
```

### 5. 查看否决原因

```bash
python main.py --pool stock_pool.txt --show-veto
```

## 五维评分模型

### 权重分配

| 维度 | 权重 | 核心指标 |
|------|------|----------|
| 成长性 | **25%** | 单季净利润同比、单季营收同比 |
| 盈利能力 | **30%** | TTM ROE、TTM 毛利率 |
| 现金流质量 | **20%** | 净现比、自由现金流收益率、销售收现比 |
| 偿债风险 | **15%** | D/E、流动比率、资产负债率 |
| 估值 | **10%** | PE-TTM |

### 评分算法

每个子指标采用 **线性得分**（0-100 分），再加权汇总：

- **正向指标**（越高越好）：`score = min(100, value / threshold × 100)`
- **反向指标**（越低越好）：`score = min(100, (1 - value / threshold) × 100)`
- **零值保护**：净利润为负时直接得 0 分

### 阈值配置

在 `config.py` → `THRESHOLDS` 中可调整各指标满分阈值：

| 指标 | 阈值 | 含义 |
|------|------|------|
| 单季净利润同比 | **≥50%** | 满分 |
| 单季营收同比 | **≥30%** | 满分 |
| TTM ROE | **≥15%** | 满分 |
| TTM 毛利率 | **≥40%** | 满分 |
| 净现比 | **≥1.0** | 满分 |
| 自由现金流收益率 | **≥3%** | 满分 |
| 销售收现比 | **≥1.0** | 满分 |
| D/E | **≤0.5** | 满分（反向） |
| 流动比率 | **≥2.0** | 满分 |
| 资产负债率 | **≤50%** | 满分（反向） |
| PE-TTM | **≤20** | 满分（反向） |

## 一票否决机制

当股票触及以下任一风险底线时，**总分直接清零**，不论其他维度得分多高：

| 规则 | 阈值 | 否决原因示例 |
|------|------|-------------|
| 现金流得分过低 | < 20 分 | "现金流得分15.3低于阈值20" |
| D/E 过高 | > 3.0 | "D/E=4.50超过阈值3.0" |
| 资产负债率过高 | > 90% | "资产负债率=95.0%超过阈值90%" |
| 经营现金流为负 | < 0 亿元 | "TTM经营现金流-50亿元为负" |

> 可通过 `--disable-veto` 禁用，或通过 `config.py` → `VETO_RULES` 调整阈值。

## 防未来函数

**核心原则：回测时只使用评估日已公开的财报数据。**

系统使用 `ann_date`（公告日）而非 `report_date`（报告期）过滤数据：

```python
# calculator.py - _filter_by_ann_date()
df = df[df['ann_date'] <= eval_ts]  # 只用已公告的财报
```

- 若某财报在评估日之后才公告，该财报不参与计算
- 若接口未提供公告日，默认估算为 **报告期 + 45 天**
- 回测时务必使用 `--date` 指定历史评估日期

## 系统特性

### ✅ 大规模并发扫描

- 基于 `ThreadPoolExecutor` 的多线程并发
- 可配置并发数（`--workers`）和请求间隔（`--rate-limit`）
- 信号量限流，防止 AkShare 反爬

### ✅ 断点续跑

- 每处理 50 只股票自动保存进度到 `.batch_checkpoint.json`
- 中断后重新运行自动跳过已完成的股票
- 使用 `--no-checkpoint` 可禁用

### ✅ 双层缓存

| 缓存层 | 位置 | 格式 | 用途 |
|--------|------|------|------|
| 文件缓存 | `.cache/{symbol}.json` | JSON | BatchRunner 快速跳过 |
| SQLite 缓存 | `scoresys_cache.db` | SQLite | DataCache 持久化存储 |

### ✅ Excel 格式化输出

- 自动生成 `score_result.xlsx`
- 中英文字段对照（如 `股票代码 (symbol)`）
- 表头深蓝色 + 数据行交替底色 + 边框 + 列宽自适应

### ✅ 模拟模式

- `--mock` 模式使用内置模拟数据（贵州茅台、五粮液、高杠杆测试股）
- 无需网络连接，适合快速验证评分逻辑和一票否决

## 模块说明

### `config.py` — 全局配置

集中管理所有可配置参数：

- `WEIGHTS`：五维权重
- `THRESHOLDS`：各指标满分阈值
- `DATA_CONFIG`：重试次数、超时、最少季度数
- `FILTER_CONFIG`：ST 过滤、负 PE 排除
- `VETO_RULES`：一票否决规则
- `INDUSTRY_CONFIG`：行业中性化配置
- `OUTPUT_CONFIG`：输出文件名、默认展示数量
- `LOG_CONFIG`：日志级别与格式

### `data_provider.py` — 数据获取层

基于 AkShare 同花顺接口获取数据：

| 方法 | 功能 |
|------|------|
| `get_combined_financials(symbol)` | 获取合并三表（利润表+资产负债表+现金流量表） |
| `get_stock_quote(symbol)` | 获取实时行情（总市值、PE-TTM） |
| `is_st_stock(symbol)` | 判断是否 ST 股票 |
| `get_industry(symbol)` | 获取申万一级行业分类 |
| `get_stock_name(symbol)` | 获取股票简称 |

**字段标准化：** 中文列名 → 英文标准列名（如 `营业总收入` → `revenue`）

**容错机制：** 自动重试 3 次，间隔 1.5 秒；无公告日时自动估算。

### `calculator.py` — 指标计算引擎

核心计算流程：

```
原始三表数据
    │
    ▼ ① 公告日过滤（防未来函数）
    │
    ▼ ② 单季拆分（累计值 → 单季值）
    │     Q1=一季报, Q2=中报-Q1, Q3=三季报-中报, Q4=年报-三季报
    │
    ▼ ③ 单季同比增速（与去年同期单季对比）
    │
    ▼ ④ TTM 汇总（最近 4 个单季求和）
    │
    ▼ ⑤ 杠杆指标（最新资产负债表）
    │
    ▼ 输出: roe_ttm, gross_margin_ttm, ocf_ttm, fcf_ttm, de_ratio, ...
```

**关键设计：**
- 扣非净利润优先（`net_profit_ex`），缺失时降级到归母净利润
- NaN 值严格处理：无法拆分时标记 NaN，不 fallback 到累计值
- 最少需要 4 个季度数据，否则指标初始化为 0

### `scorer.py` — 五维评分器

| 方法 | 功能 |
|------|------|
| `growth_score()` | 成长性评分（净利润同比 60% + 营收同比 40%） |
| `profitability_score()` | 盈利能力评分（ROE 70% + 毛利率 30%） |
| `cashflow_score()` | 现金流评分（净现比 40% + FCF收益率 30% + 收现比 30%） |
| `leverage_score()` | 偿债风险评分（D/E 40% + 流动比率 30% + 资产负债率 30%） |
| `valuation_score()` | 估值评分（PE-TTM 反向） |
| `total_score()` | 综合评分 + 一票否决检查 |
| `industry_adjusted_score()` | 行业百分位中性化调整（待扩展） |

### `batch_runner.py` — 批量运行器

支持全市场 4000+ 股票的稳定扫描：

- **并发控制**：`ThreadPoolExecutor` + `Semaphore` 双重限流
- **进度追踪**：实时显示进度条、速度、ETA
- **断点续跑**：每 50 只保存一次进度
- **缓存管理**：自动读写 `.cache/` 目录

### `utils.py` — 辅助工具

| 函数 | 功能 |
|------|------|
| `filter_st_symbols()` | 批量过滤 ST/*ST 股票 |
| `get_trade_calendar()` | 获取 A 股交易日历 |
| `is_trade_day()` | 判断是否为交易日 |
| `get_latest_trade_day()` | 获取最近交易日 |
| `load_stock_pool()` | 从文件加载股票池 |

### `utils_cache.py` — SQLite 持久化缓存

| 表 | 用途 |
|----|------|
| `financials` | 财务数据（按 symbol + report_date 主键） |
| `quotes` | 行情数据（按 symbol + quote_date 主键） |
| `industries` | 行业分类（按 symbol 主键） |

支持按日期范围查询、批量读取、统计信息、自动清理。

### `main.py` — 主程序入口

职责：
1. 解析 CLI 参数
2. 加载股票池（CLI 指定或文件加载）
3. 执行批量评分（`BatchRunner`）
4. 控制台格式化输出（中文字段名）
5. 导出 Excel（`score_result.xlsx`）

## 缓存与断点

### 文件结构

```
ScoreSys/
├── .cache/                        # JSON 文件缓存
│   ├── 600519.json
│   ├── 000858.json
│   └── ...
├── .batch_checkpoint.json         # 断点续跑进度
└── scoresys_cache.db              # SQLite 持久化缓存
```

### 缓存管理

```bash
# 清理 7 天前的缓存（默认）
python main.py --clear-cache

# 清理 30 天前的缓存
python main.py --clear-cache --cache-days 30

# 禁用缓存（每次重新拉取）
python main.py --pool stock_pool.txt --no-cache

# 强制刷新缓存
python main.py --stocks 600519 --force-refresh

# 禁用断点续跑
python main.py --pool stock_pool.txt --no-checkpoint
```

### 断点续跑

中断后重新执行相同命令，已完成的股票自动跳过：

```bash
# 第一次运行（假设处理到 200 只时中断）
python main.py --pool stock_pool.txt --workers 5

# 重新运行，自动从第 201 只继续
python main.py --pool stock_pool.txt --workers 5
# 输出: [断点续跑] 已跳过 200 只已完成股票，剩余 XXX 只
```

## 注意事项

1. **网络依赖：** 真实模式需要网络连接，依赖 AkShare 接口可用性
2. **金融股特殊：** 银行/保险等金融企业杠杆指标不适用当前模型，需单独建模
3. **公告日估算：** 若接口无 `ann_date`，默认估算为报告期 + 45 天，可能与实际公告日有偏差
4. **扣非净利润：** 优先使用扣非净利润，缺失时降级到归母净利润
5. **NaN 处理：** 单季拆分时无法计算则标记 NaN，不 fallback 到累计值
6. **并发建议：** 并发数不超过 10，请求间隔不小于 0.2 秒，避免被 AkShare 限流
7. **回测日期：** 回测时务必使用 `--date` 指定历史日期，否则无法防未来函数
8. **ST 过滤：** 默认排除 ST/*ST 股票，可通过 `config.py` → `FILTER_CONFIG` 调整
9. **行业中性化：** 当前为框架阶段（`enable: False`），需补充行业统计数据后启用
