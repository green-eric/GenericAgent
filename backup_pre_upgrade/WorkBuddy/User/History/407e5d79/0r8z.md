
## 🧮 TTM ROE 计算验证

### 计算公式验证
```
ROE_TTM = 净利润TTM / 净资产 × 100
其中：
- 净利润TTM = Q1净利润 + Q2净利润 + Q3净利润 + Q4净利润
- 净资产 = 最新季度末的净资产数据（时点数）
```

### 示例验证 (300502.SZ - 新易盛)
- **净利润TTM**: 915,114万元
- **净资产**: 180,642万元
- **计算过程**: 915,114 ÷ 180,642 × 100 = 50.66%
- **结果确认**: ✅ 与系统输出一致
