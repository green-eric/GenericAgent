# ThinkPad X13 内存优化指南

## 📋 优化概览

针对你的 **ThinkPad X13 Gen 2i (16GB内存)** 进行系统级优化，缓解内存瓶颈问题。

---

## 🚀 优化项目清单

### 1. 虚拟内存优化 ⭐核心优化
- **设置**: 初始 8GB → 最大 24GB
- **位置**: C:\pagefile.sys
- **效果**: 大幅缓解内存不足导致的卡顿和崩溃

### 2. 系统服务优化
- **禁用 SysMain (Superfetch)**: 减少后台内存占用
- **禁用 Windows Search**: 减少索引服务内存占用
- **效果**: 释放 500MB-1GB 内存

### 3. 磁盘清理
- 清理临时文件
- 清理系统缓存
- **效果**: 释放C盘空间，为虚拟内存留出余地

### 4. 启动项优化
- 禁用不必要的开机启动程序
- **效果**: 加快启动速度，减少开机内存占用

## ⚡ 使用方法

### 一键优化（推荐）

1. **右键点击** `内存优化脚本.bat`
2. 选择 **"以管理员身份运行"**
3. 等待脚本执行完成
4. 按提示 **重启电脑**

### 手动设置虚拟内存

如不想运行脚本，可手动设置：

1. 右键 **"此电脑"** → **"属性"**
2. 点击 **"高级系统设置"**
3. 性能区域点击 **"设置"** → **"高级"** 选项卡
4. 虚拟内存区域点击 **"更改"**
5. **取消勾选** "自动管理所有驱动器的分页文件大小"
6. 选择 **C盘** → **"自定义大小"**
7. 输入：
   - 初始大小: `8192`
   - 最大大小: `24576`
8. 点击 **"设置"** → **"确定"**
9. **重启电脑**

## ⚠️ 注意事项

1. **必须重启**: 所有更改需重启后才能生效
2. **管理员权限**: 脚本必须以管理员身份运行
3. **C盘空间**: 确保C盘有至少 30GB 可用空间
4. **还原点**: 脚本已自动创建系统还原点，可随时恢复

---

## 🔧 恢复默认设置

如需恢复原始设置，运行以下命令（管理员权限）：

```batch
wmic computersystem where name="%computername%" set AutomaticManagedPagefile=True
sc config SysMain start= auto
sc config WSearch start= auto
```

然后重启电脑。

## 💡 额外建议

### 日常使用优化
1. **浏览器**: 限制标签页数量，关闭不必要的扩展
2. **软件**: 关闭不用的程序，避免同时运行多个大型软件
3. **监控**: 使用任务管理器监控内存使用情况
4. **清理**: 定期运行磁盘清理工具

### 长期方案
- 如16GB内存长期不足，建议考虑更换支持内存扩展的笔记本
- 或使用外接显卡坞(eGPU)分担图形处理压力

## 📞 问题排查

| 问题 | 解决方案 |
|------|---------|
| 脚本无法运行 | 确保以管理员身份运行 |
| 虚拟内存未生效 | 检查C盘空间是否充足 |
| 系统变慢 | 可能是虚拟内存设置过大，调小最大值为16GB |
| 搜索功能失效 | 重新启用 Windows Search 服务 |
