# A股智能选股分析系统 - 项目总结

## 项目概述
成功构建了基于多维度业绩评价方案的A股智能选股分析系统，实现了TTM滚动财务指标计算、行业百分位评分和综合评级功能。

## 核心功能实现

### 1. TTM财务指标计算
- **滚动十二个月(TTM)数据**：自动拼合最近四个季度财报数据
- **消除季节性扰动**：通过连续季度数据平滑处理
- **关键指标**：扣非ROE、毛利率、净利率、营收/利润增速等

### 2. 五维度评价体系
按照建议方案完整实现：

| 维度 | 指标 | 权重 |
|------|------|------|
| 盈利能力 | TTM扣非ROE、毛利率、净利率 | 35% |
| 成长性 | 营收同比、利润同比、单季环比 | 30% |
| 盈利质量 | 经营现金流/净利润、应收账款占比 | 15% |
| 运营效率 | 总资产周转率、存货周转率 | 10% |
| 偿债风险 | 资产负债率、利息保障倍数 | 10% |

### 3. 行业百分位评分
- **跨行业可比性**：同行业内每个指标转换为0-100百分位得分
- **动态排名**：确保不同行业公司间公平比较
- **特殊处理**：持续亏损+现金流为负直接E级；盈利质量严重不达标降级

### 4. A~E分级体系
- **A级(80+分)**：绩优股，综合业绩优秀
- **B级(60-79分)**：良好，具备投资价值
- **C级(40-59分)**：一般，需谨慎评估
- **D级(20-39分)**：较差，存在风险
- **E级(<20分)**：高风险，不建议投资

## 技术架构

### 主要文件
1. `ultimate_analyzer.py` - 完整的主分析系统
2. `ultimate_analyzer_simple.py` - 简化版便于演示
3. `show_report.py` - 报告展示和分析脚本

### 依赖库
- **pandas** - 数据处理和分析
- **numpy** - 数值计算
- **openpyxl** - Excel文件读写
- **asyncio** - 异步并发处理

## 使用指南

### 运行环境
- Python 3.8+
- 所需包: pandas, numpy, openpyxl

### 运行步骤
1. 安装依赖: `pip install pandas numpy openpyxl`
2. 准备股票列表文件 (xuan.txt格式)
3. 运行主程序: `python ultimate_analyzer.py`
4. 查看桌面生成的Excel报告

### 股票列表格式
支持两种格式：
```
代码:名称
代码 名称
```

### 输出说明
Excel报告包含：
- **综合评价结果**：所有股票的详细指标和评分
- **绩优股(A级)**：筛选出的A级股票
- **统计概览**：评级分布和行业分析
